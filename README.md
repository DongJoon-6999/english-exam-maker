# 모의고사 영어 서술형 요약 문제 생성기 (English Summary Problem Generator)

모의고사, 수능, 교과서 영어 지문을 복사해 붙여넣으면, 고등학교 내신 및 수능 서술형 킬러 문항 양식(요약문 빈칸 완성, 어형 변형, 기능어 추가 조건)의 문제를 자동으로 생성해주는 웹 프로그램입니다.

---

## 🚀 빠른 실행 방법 (Windows)

1. `run.bat` 파일을 더블 클릭하여 실행합니다.
2. 자동으로 브라우저(`http://127.0.0.1:8000`)가 열립니다.

또는 터미널(PowerShell/CMD)에서:
```bash
cd C:\Users\dong6\.gemini\antigravity\scratch\english-summary-problem-generator
pip install -r requirements.txt
python app.py
```

---

## 🌟 주요 기능

1. **지문 입력 및 맞춤형 출제**:
   - 영어 지문을 붙여넣기만 하면 핵심 주제를 관통하는 고난도 요약문 자동 작성
   - (선택) 원하는 핵심 문법(예: `관계대명사`, `분사구문`, `가주어-진주어`, `5형식 사역/지각`)이나 중요 어휘 지정 가능
2. **실제 시험지 양식의 서술형 문항 생성**:
   - **지시문**: "■ 윗글의 내용을 한 문장으로 요약하고자 한다. <보기>에 주어진 단어를 활용하여 빈칸 (A)에 들어갈 말을 영어로 쓰시오. (단, <조건>에 맞게 쓸 것)"
   - **요약문**: 빈칸 `(A)` 지정
   - **`<단어>`**: 단어를 원형(lemma)으로 변환 후 무작위 셔플링
   - **`<조건>`**: 기능어 추가 및 필요시 단어 변형 조건 제시
3. **다중 후보 (2~3개) 동시 생성**:
   - 서로 다른 문법 구문과 주제 각도를 가진 2~3개의 후보 문제 중 선택 가능
4. **교사용 정답 & 상세 해설 제공**:
   - 완성 문장, 빈칸 정답, 자연스러운 한글 번역
   - 추가된 기능어 및 단어 원형→변형 목록 표
   - 출제 의도 및 핵심 문법 구조 해설
5. **학생용 실습 모드**:
   - 학생이 웹 화면에서 직접 타이핑하여 영작해보고 즉시 채점 및 피드백 확인
6. **한글(HWP) 및 Word 원클릭 복사**:
   - **한글(HWP) 복사**: 테두리 상자(Box) 서식이 유지된 채 한글(HWP) 및 MS Word에 바로 붙여넣기 가능
   - **문제만 복사(학생용)** 및 **정답/해설 포함 전체 복사(교사용)** 지원
   - **인쇄(Print Preview)** 기능 지원
7. **Gemini & OpenAI 멀티 모델 지원**:
   - Google Gemini (Gemini 2.5 Flash / 1.5 Flash / 1.5 Pro)
   - OpenAI (GPT-4o / GPT-4o-mini)
   - API 키가 없는 경우에도 즉시 사용 가능한 스마트 모의(Mock) 모드 내장
